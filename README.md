## 🌟 About The Project

**Iqra' 6 Digital Tutor** bridges traditional Quranic learning with modern artificial intelligence. Iqra' Book 6 represents the pivotal transition stage in Quranic literacy, introducing complex Waqaf (pausing rules), advanced Nun Sakinah and Tanwin rules, Nun and Mim Musyaddadah, and extended Madd articulations.

This platform transforms self-study into an engaging, feedback-driven experience. With crystal-clear Arabic typography, audio pronunciation, real-time Gemini AI Tajweed guidance, and interactive AI chat tutoring, learners of all ages can gain confidence and fluency in Quran recitation.

---

## ✨ Features

- 🎙️ **Voice Recitation Guidance** — Listen to accurate Arabic pronunciations for complex words and Quranic passages.
- 🤖 **Gemini AI Tajweed Tutor** — Instant, context-aware breakdowns of articulation points (Makharij) and recitation rules.
- 💬 **Interactive AI Chat Assistant** — Ask questions anytime about Quranic rules, pronunciation nuances, and lesson context.
- 📚 **Comprehensive Lesson Path** — Fully structured curriculum covering every lesson of Iqra' Book 6.
- 📊 **Progress & Multi-Profile Tracking** — Built-in profile manager with individual lesson completion tracking and milestone celebrations.
- 🎉 **Celebratory Feedback** — Rewarding interactive milestones with custom confetti celebrations upon lesson completion.
- ⚡ **Lightning Fast & Modern** — Ultra-responsive UI powered by React 19, Tailwind styling, and Vite.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18 or higher recommended)
- npm, pnpm, or yarn
- Google Gemini API Key ([Get one free from Google AI Studio](https://aistudio.google.com/))

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kecrwn/IQRA_6.git
   cd IQRA_6
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the project root:
   ```env
   GEMINI_API_KEY=your_google_gemini_api_key_here
   ```

4. **Launch the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   npm run preview
   ```
